# 贪吃蛇（Snake）

一个运行在浏览器中的经典贪吃蛇小游戏。

## 使用技术

- 原生 HTML5
- 原生 CSS3
- 原生 JavaScript（ES5/ES6，无框架、无第三方库）
- HTML5 Canvas 2D 绘图

## 当前开发阶段

第二阶段：蛇的移动与方向控制。目前已完成：

- 24 x 24 网格（每格 25px）上的蛇身绘制，蛇头与蛇身用颜色区分
- 固定节奏移动，每秒 8 格
- 键盘控制：WASD 与方向键等价，两个方向均可操作
- 屏幕方向按钮：Canvas 下方的上下左右十字按钮，点击或触摸即可转向
- 转向规则：禁止 180° 回头，同一移动间隔内最多缓存两步转向
- 边界穿墙：蛇从一侧移出后从对侧出现
- 开始提示：绘制在 Canvas 内蛇的下方，按周期渐显渐隐，游戏开始后自动消失

尚未实现：

- 食物生成与蛇身增长
- 自身碰撞与边界判定
- 分数、游戏结束与重新开始

## 操作方式

页面打开后蛇静止不动，Canvas 内蛇的下方会显示渐显渐隐的操作提示，
按 WASD、方向键或下方方向按钮后开始移动，提示同时消失。
如果按键没有反应，先用鼠标点击一下画布，让页面获得键盘焦点。

## 调试接口

浏览器控制台可通过 `window.__snakeDebug.getState()` 查看当前状态快照
（`state`、`direction`、`head`、`snakeLength`、`pendingDirections`），
该接口只读，仅供调试与自动化验证使用。
