# 贪吃蛇（Snake）

一个运行在浏览器中的经典贪吃蛇小游戏。

## 使用技术

- 原生 HTML5
- 原生 CSS3
- 原生 JavaScript（ES5/ES6，无框架、无第三方库）
- HTML5 Canvas 2D 绘图

## 当前开发阶段

基础结构搭建阶段。目前已完成：

- `index.html`：HTML5 基础页面，引入样式与脚本，包含游戏用的 Canvas 元素
- `style.css`：基础页面布局、Canvas 居中显示与简单背景样式
- `game.js`：JavaScript 入口与初始化函数

尚未实现：

- 蛇的移动
- 食物生成
- 碰撞检测
- 分数与游戏结束等逻辑
